lens: dead surface area.

find code that exists but does no work: pub items nothing in the workspace calls,
feature flags no build enables, cfg branches no configuration reaches, deps where we
use one function from a crate pulling ten, trait impls nobody dispatches through,
and generated code (proto) messages nothing constructs.

method- work from the leaves in. for every `pub` item in a crate, grep the workspace
for uses outside its own crate; if only tests use it, ask whether the test is testing
anything real. for every feature in every Cargo.toml, find the build/CI invocation
that enables it- no invocation, no feature. check each dependency's used surface with
grep before trusting it.

deleting dead code is the only reduction that is always correct. but be careful about
*almost* dead: code kept deliberately for an upcoming design (check prompts/, recent
commits, and ask me) is not dead, it's early. flag those separately.

output: table of (item, file:line, evidence it is dead, lines saved). then delete in
one commit per crate so review is easy.
